# Руководство Lineament Analyzer 1.0

## Проект и DEM

1. В разделе **Данные** откройте одноканальную GeoTIFF DEM. Проверьте CRS, разрешение и единицы высот.
2. В разделе **Анализ рельефа** выберите высоту, теневой рельеф, уклон, экспозицию или TPI. При необходимости укажите единицы высот и Z-factor.
3. Масштабируйте карту колёсиком и перемещайте перетаскиванием. Используйте команду масштабирования к данным для просмотра всего растра.
4. В меню **Файл** сохраните проект .laproj. При восстановлении требуется исходный GeoTIFF по записанному пути. Автоматическое восстановление последней DEM включается отдельно.

## Обнаружение и сравнение

1. Выберите алгоритм и профиль в разделе **Обнаружение**. Для крупных DEM начните с предпросмотра. Результат сохраняет режим, сетку, размер пикселя и привязку обработки.
2. В полном разрешении установите бюджет памяти. Для глобальных методов при превышении бюджета уменьшите область анализа.
3. Для интерактивного A* нажмите **Выбрать две точки A\*** и укажите концы на карте. Оба конца и маршрут должны иметь поддержку откликом. Кнопка **Обнаружить** запускает автоматический режим.
4. У направленных методов **Показать отклик** отображает сводную карту при номере компонента 0 и отдельный компонент при положительном номере. Для сводной карты доступен цвет по ориентации растровой сетки. Повторное применение слоя возвращает исходное изображение.
5. В разделе **Сравнить результаты** отметьте методы и запустите расчёт. В списке результатов доступны отдельные методы, уникальные линии и Algorithm Consensus. Таблица Consensus показывает происхождение каждой согласованной линии.
6. Настраивайте постобработку в пикселях фактической сетки. В разделе статистики доступны длины, классы, плотность и роза направлений.

## Валидация и экспорт

1. В разделе **Валидация** выберите DEM и эталонный GeoJSON, Shapefile или слой GeoPackage. При отсутствии CRS введите подтверждённый код EPSG или WKT. Для проверки программы можно создать синтетический набор.
2. Выберите методы, допуск в метрах и угловой допуск. При необходимости добавьте постобработку и консенсус. Просмотрите таблицу, карту совпадений, диаграмму ошибок и розы направлений.
3. Экспортируйте полный Validation Report в HTML или JSON и метрики в CSV. Сохраните описатель набора для повторной проверки.
4. В разделе **Экспорт** выберите набор линий и формат. GeoJSON записывает координаты WGS84. Shapefile и GeoPackage используют CRS DEM. Переносите Shapefile вместе с .dbf, .shx, .prj, .cpg и .metadata.json.

Линии требуют геологической интерпретации. Shearlet экспериментальный.
Confidence отражает поддержку метода. Синтетическая проверка измеряет
восстановление заранее заданной геометрии.
